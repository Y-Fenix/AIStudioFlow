# 多语言静态检查

全量巡检默认包含“系统 → 多语言”。复用现有逐功能 `deep-v2` dossier、七维 coverage 和完成门禁，不另建报告页签。目标是给出当前代码和语言资源支持的结论，不把检查工作交给用户。

## 从真实入口建立范围

- 从模块索引、Framework 本地化章节和实际语言注册确定支持语言、默认语言、地区变体和回退规则，不写死语言数量。按项目 CodeGraph 协议定位 `LocalizeManager`、`UIUtils.Lang`、`LangConvert`、`DynamicText` 等实际入口及调用方，名称只是定位线索，不能以入口存在判通过。
- 交叉核对运行时 StringTable/Shared Data、源 CSV、代码与 Prefab 的 key 引用、动态拼 key、模块加载和热更资源。CSV 有译文不代表已接入运行时；以实际读取资源为准。`文档/开发文档/外围模块/MultiLava多语言接入文档.md` 有 CSV 与运行时交付边界及换行历史，读取当前适用记录，不把历史验证当本轮证据。
- 先发现并核实现有语言校验工具及其覆盖，复用适用入口；补齐其漏掉的动态 key、页面刷新和资源消费链。共享本地化管理器与各功能接入分别审查，礼包、活动、排行榜等消费者不能仅引用公共入口便算完成。

## 必查链路

按以下可独立判定的功能点建立审查记录，每项覆盖真实适用的七维场景；不适用需给具体依据。

| 功能点 | 自动静态检查与补证 |
| --- | --- |
| 翻译资源完整性 | 对每种支持语言核对实际可达 key、缺项、重复 key/ID、空值、集合注册与打包引用；沿真实回退链判断最终显示，区分允许留空、可回退和确定缺文案。未引用条目仅作清单，不直接算 Bug；动态 key 展开实际可取值，不能因文本搜索未命中就判缺失 |
| 参数与文案格式 | 按生产使用的格式器检查参数数量、索引/名称/类型、转义大括号、真实换行与字面反斜杠、富文本闭合及适用的复数/数字/日期格式。逐调用核对实参，用真实格式化入口与代表输入本地补证；不以通用正则替代实际格式规则 |
| 默认语言与切换 | 系统语言映射、地区变体、不支持语言回退、冷启动与保存偏好、切换后已打开/重开页面、静态缓存和动态文案刷新、订阅注销；推导快速连续切换及旧异步资源晚返回，确认不会用旧语言覆盖新选择 |
| 字体与图文资源 | 沿各语言实际字体、动态字体源、fallback、材质和图集映射核查可达字符与资源引用；遵守 Framework §3.3.5 的 TMP 字体/材质同源规则。静态图集缺字不等于最终缺字，须查动态补字及 fallback。检查语言图片/艺术字变体、缺资源回退和切换后旧资源缓存 |
| 配置更新与数据恢复 | 后台/热更语言资源的加载、缓存失效、失败回退与刷新通知；保留旧本地偏好、清本地恢复同身份、清本地新身份三条数据链；按实际数据归属检查，不假设语言偏好必定在云档中，也不要求安装卸载 |

布局仅对源码、文本和实际布局约束能证明的问题给确定结论。译文较长不自动等于截断，语言相似不自动等于错译，RTL/复数等只按项目实际支持范围检查。缺权威依据的翻译语义、真实设备排版和外部实际下发仅记静态范围限制，不新增人工验收任务；可本地判断的资源/刷新链仍必须查完。

## 报告与收口

在现有“系统”页签分组为“多语言”，按上表用白话展示查了什么、结果和已证问题。缺陷精确写出影响语言、key、页面/功能、触发输入或切换顺序、预期/实际、原因以及源码/运行时资源位置。有确定玩家路径再附黑盒步骤，否则提供 Agent 已完成的白盒推导或本地复现输入与日志，不要求同事接着执行。

未读完的调用链进入自动续查队列；静态完成且未见问题标绿，已证缺陷标红，条件风险或未完成标棕。仅补本检查规则不修改历史报告状态，也不声称项目多语言已经审完。
