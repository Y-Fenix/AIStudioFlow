# 固定测试范围

唯一机器清单为 `assets/audit-scope.json`。每次无参数调用必须完整加载，不从 dossier、已登记 Runner 或旧报告反推范围。本版固定 90 项：玩法 28、关卡 5、系统 47、配置 6、埋点 4。编号、业务名和分类固定；发现新功能先更新清单，不把它随手合并到旧大项。固定的是检查对象和必查内容，Bug 数、是否查完、结论仍取本轮证据。

## 总控先锁范围再派工

由总控自动执行，同事仍然只输入 `$gagasort-qa`：

```sh
python3 -B <skill目录>/scripts/audit_scope.py prepare \
  --root <被测游戏仓库绝对路径> \
  --evidence-dir <本轮QA/results目录> --run-id <本轮唯一ID>
```

输出 `scope-lock.json` 和 `feature-inventory.json`。后者是未审查骨架，整体复制其 `features` 和 `scope_control` 到本轮基础数据，并补齐报告契约其他字段；不得筛掉没有 dossier 的项。`inventory_sources` 是候选源码，`source_paths` 仅填实际读过并存快照的依赖，两者不能混算。锁记录清单指纹、完整编号、源码入口映射/哈希、模块索引、HEAD、分支和子模块状态，不能重复覆盖；盘点不是业务测试通过。

prepare 返回 2时先读 `errors / unassigned_sources`：未归属源码须补到具体功能或有依据的排除项，入口消失须查证迁移、退役或子模块初始化，不能直接删除旧功能。修订清单须更新 scope_version、workflow_version 和本页目录，重新创建本轮目录并锁定；既有已审证据是否可复用须逐项复核，不能改旧锁冒充新基线。

派工引用固定 ID、`check_targets` 以及本轮候选入口，每个功能保留独立 dossier 记录。每条 dossier `checks[]` 用 `scope_targets` 数组引用它实际覆盖的 `check_targets` 原文，允许多条场景覆盖同一目标；合并后写入 `static_audit.cases[].scope_targets`。每个固定目标至少关联一个有源码证据且结论闭合的真实场景，否则该功能未完成。标签不能代替分支、输入和推导；七维深审门禁继续生效。

## 合并与交付门禁

```sh
python3 -B <skill目录>/scripts/audit_scope.py check \
  --root <被测游戏仓库绝对路径> --evidence-dir <本轮QA/results目录> \
  --data <本轮report-data.json>
```

输出 `scope-check.json`。缺编号、多余编号、重复、改分类或业务名、缺锁、清单/源码/索引/基线变化都返回 2。`merge_domain_audits.py` 合并前、`audit_completion.py` 续查、`quality_gate.py` 计数和 `finalize_report.py` 交付再次核范围；少做功能不能通过“全量完成”。最终交付还要查完全部功能、配置与逐关任务，范围对上本身不代表完成深审。

定向检查只有用户明确要求时才允许，须在数据里写 `scope_control: {mode: targeted, reason: 用户原定向范围, feature_ids: [实际编号]}`。默认缺 mode 按全量处理。全量 `finalize_report.py` 不接受 targeted，不能为缩短运行时间偷偷改模式。

## 每项公共必查线

每项均检查入口正常链、边界异常、重复异步、状态持久化、配置变化、升级重装和跨模块影响。安装链仅静态推导：保留本地升级、清本地恢复同身份、清本地新身份；不执行安装卸载，不生成正常功能人工待办。

配置逐字段、关卡逐条、语言逐语言、埋点逐事件/属性自动展开成子清单；本表是稳定的功能组，不能用“5项关卡检查”代替实际逐关执行，也不能用“1项多语言”代替全部语言检查。每轮增加的关卡/参数/语言/事件进入专项子清单，不靠新增顶层编号凑数。

源码发现根为 GamePlay、Framework、AWFramework 和 Features。Editor 工具实现与第三方 UISoftMask 不逐行深审，理由固定在清单 exclusions；生产关卡导出/校验/求解和 UI 调用边界仍在范围。未初始化的空功能壳不假称已有业务。扫描器能发现未归属文件和执行期间变化，无法自动理解同一旧文件里新增的业务含义；总控仍须交叉核对模块索引、开关枚举和代码入口，发现后维护清单。不能把文件匹配称为功能已测。
