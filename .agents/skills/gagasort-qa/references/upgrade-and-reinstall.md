# 逐功能覆盖安装与卸载重装的静态影响分析

## 默认目标

用户说“检查覆盖安装、删除安装对每个功能的影响”，默认是**代码静态分析**：追踪持久化、旧数据读取、初始化、迁移、云合并及业务消费者。不是实际安装应用，也不是生成一张因缺包、缺设备而全部受阻的操作表。

不需要用户提供旧安装包、设备、账号即可开始并交付当前代码层面的结论。已有本地测试可补强证据；未运行探针不妨碍静态结论，但必须标清证据层级。只有用户另行明确要求，才安排真实安装验收。

## 三种数据条件

每个功能逐项判断，引用实际字段和调用路径，不套用相同“存档会恢复”结论。

| 条件 | 从代码核查什么 | 应给出的影响结论 |
| --- | --- | --- |
| UPG 覆盖安装：原应用本地数据保留 | 文件/PlayerPrefs键和序列化格式；新字段默认与迁移；版本门禁；旧期号、资格、领取标记、订单、残局及资源指纹如何被新代码消费；二次读取的幂等性 | 哪些旧状态继续使用、被迁移、被拒绝或重建；可能丢失/重复/卡住的具体条件与根因 |
| REI-SAME 卸载重装：应用本地数据清除，之后恢复同一游戏身份 | 无本地档的构造与注册；功能是否实际上传云端、登录合并名单、身份和版本比较；商店恢复的真实入口；云档恢复后的消费者初始化 | 哪些状态只在本地因而丢失，哪些在云同步且同身份成立时可恢复，哪些权益依赖外部；不能假设同账号恢复全部进度 |
| REI-NEW 卸载重装：应用本地数据清除，建立全新游戏身份 | 新档默认、引导与解锁、设备级设置、静态缓存、登录回调、旧身份残留、商店账号与游戏账号的归属 | 首次状态是什么，是否存在旧账号/旧期号污染路径；“新身份已建立”是分析条件，不能保证系统会给新UID |

分别标注本地文件、PlayerPrefs、内存、云档、平台身份/Keychain、商店权益。操作系统备份、iOS Keychain和商店交易记录不属于普通本地清除假设；仓库能查到模板配置或集成代码就分析，查不到才列外部假设。不能因这些变量未实测而跳过静态路径。

## 每个功能的证据

1. **状态归属**：具体 Archive 类和字段、键名、CanUploadData，或确实不持有跨进程状态；共享状态连到实际消费者。
2. **保留旧数据**：读取入口 → 默认/迁移/拒绝 → 消费入口。检查进行中目标冻结、期号、已领标记、购买资格、延迟订单及旧资源版本。
3. **清除本地数据**：CreateNewData/初始化 → 登录/云合并 → OnLogin或登录后初始化 → 功能状态。核对上传和登录合档两侧，不能仅凭CanUploadData=true断言能恢复。
4. **风险与原因**：使用“发现问题 / 条件风险 / 当前路径未见明显冲突 / 局部审查有缺口 / 工具本体不涉及玩家安装”等准确结论。静态未发现冲突不等于跨版本实测通过。
5. **来源**：生产路径、类/方法、有效行号，必要时保存源码摘录和哈希。只查通用Archive而未查消费者时，标明具体功能缺口，不能算逐功能审完。

纯表现功能检查状态来源、资源重载与初始化；编辑器/求解/回放工具检查历史输入格式、资源路径与配置兼容。不能仅填“N/A”而跳过与玩家内容有关的生成结果。

## 旧版本与本地探针

当前源码足以分析持久化归属、默认、恢复与风险路径。需要判断字段/类型/键或旧资源是否变化时，用仓库已确认的发布记录、已有历史源码与脱敏夹具。没有可信旧版本映射时，仅将“指定发布版本之间的差异/迁移兼容”标待核，不把全部静态分析标受阻；Git tag本身不等于发布证明。

可复用真实生产接缝做缺字段、旧合法值、云档有无、初始化顺序和迁移幂等等探针。保留生产算法及有效断言，不改正式存档。合成输入标为合成输入，不宣称真实旧包兼容通过。现有版本门禁、存档持久化、指纹升级和模块自身Archive/资格/生命周期测试按需复用。

编译依赖不足只阻塞对应动态断言，静态检查继续。默认不安装/卸载应用，不访问真实账号、商店或玩家数据。

## 交付

`installation.csv`以**逐功能静态影响矩阵**为主体：功能 ID、状态/字段归属、链路、静态结论、具体影响、归因、生产证据、剩余代码或业务契约缺口、本地探针补证。三条链路每个功能都有判断，不用100条同文案的共性模板充数。

HTML在各功能详情中展示三条数据链的静态影响与归因，提供可复核的白盒输入、推导路径与源码证据。保留/恢复/新身份初始化什么，用人话直接给结论；不再强制每个功能先做一张黑盒验证卡，不以缺准确按钮、包、设备或人工执行结果拖住静态收口。

只有存在可核定玩家路线或用户明确要求时，才将对应外部复现写入 `manual.md`；普通静态场景不生成该文件。用户明确要求实装验收时，才另建设备表和包/签名/旧样本准备单，它不替代本静态矩阵。
