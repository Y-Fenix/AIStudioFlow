## 实现与边界

- 默认流程保留原数据；新流程独立保存输入、Skill、交付、审批、操作日志、修订与任务。固定测试节点绑定独立批次，不能切换到其他流程的批次。
- 普通部门、测试批次、节点问答分别使用 3 / 3 / 2 个工作线程；同流程同节点、同测试批次拒绝重复在途任务。新流程手动推进节点，测试批次保留已有全自动决策能力。
- 节点助手持久保存提问、回答和来源，自动读取同流程有权访问的已保存资料；跨部门/其他流程仅使用明确关联且当前已确认的交付。来源修改提示过期，撤权隐藏相关回答，旧回答也不能把已移除来源带回新提问。
- 每次来源正文总预算 32,000 字符，单来源最多 10,000；历史最多返回 50 条。超出明确标记截取，不保证一次读入所有长需求或全部用例。
- 助手只读，不审批、不执行节点、不发布。服务重启将运行中问答标记中断，需手动重试。节点执行继续经过权限、修订和证据门禁。
- 修复 macOS 拒绝进程组清理时覆盖模型原始错误、阻断可重试请求的问题；修复流程读取未释放 SQLite 游标导致与并发写入互相等待的问题。
