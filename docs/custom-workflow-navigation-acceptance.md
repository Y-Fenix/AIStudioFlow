# 自定义工作流导航验收

日期：2026-10-22。用户已确认方案，按现有公共平台增量实现。

## 已实现

- 项目总览仅展示产品、设计、开发、测试四部门；左侧保留一个自定义工作流集合入口。
- 工作流列表支持名称搜索、最近运行状态筛选、10 / 20 / 50 条分页、复制、重命名和归档；返回保留列表条件与页码。
- 进入流程先展示业务节点首页，节点间显示箭头、自动执行 / 手动继续开关。编辑流程和编辑内部积木使用独立入口。
- 每个节点实例有独立输入及 Skill 覆盖配置；支持 Skill 选择、导入、导出、恢复默认，不修改来源部门节点。
- 新运行冻结配置、Skill、输入与节点顺序；历史视图只读。人工输入、清单、审核、测试证据及权限门禁继续生效。
- 结果与操作日志按运行和节点展示，北京时间显示；轮询保持编辑内容、焦点与滚动。
- 保留旧工作流积木 ID 和历史运行。旧快照缺少 groups 时按步骤推导权限范围，包含 root 原始积木和带尾部分隔符的引用实例。
- 修复预置节点资料在人工输入后丢失，以及无 Skill 查看权限时无法单独保存输入的问题。明确修改 Skill 仍需要对应权限。
