# Codex Skill 本机交接

## 目标

在部门节点的 Skill 控件旁加入“在 Codex 使用”。用户点击后，当前 Mac 上安装的 StudioFlow 桥接工具打开 Codex，并把部署指令和当前 Skill 内容填入输入框；平台不自动发送，用户自行按 Enter。Codex 的文件写入及覆盖确认继续由 Codex 自己处理。

## 架构

- StudioFlow 网页通过已登录的同源 API 创建短时一次性交接票据。创建票据前，服务端对当前工作室、项目、节点重新检查 Skill 导出权限。
- 票据绑定创建者和准确节点，数据库只存票据哈希、目标、内容及过期时间。自定义 URL 只包含不可猜测票据，不包含 Skill 文本。
- 每台 Mac 安装并注册 `studioflow-codex://` 协议的轻量桥接 App。桥接 App 用一次性票据从原 StudioFlow HTTPS 来源取回交接内容，然后将 Codex 安装请求复制到剪贴板、启动 Codex 并辅助粘贴。只粘贴，不模拟 Enter。
- Skill 作为待创建文件的正文放进 Codex 提示，目标路径为当前 macOS 用户的 `~/.codex/skills/studioflow-<department>-<node-index>/SKILL.md`。该路径由稳定部门 ID 和节点编号生成，不受导入 Skill 名称影响。提示要求 Codex 将正文作为文本处理、不得执行 Skill 内命令、目标已存在时先询问用户，并在完成后回报文件路径。

## 安全与失败处理

- 交接票据短时、单次消费，并在兑换时确认创建用户仍为活跃账号、且该用户当前仍有对应节点查看和 Skill 导出权限；正文不进入 URL、访问日志或浏览器历史。
- 票据创建受项目、部门、节点及 Skill 导出权限保护。用户不得用该入口取得其他项目或其他人的 Skill。
- 桥接工具只接受 HTTPS 站点（本机开发的回环地址除外），限制请求体大小，并清理已消费和过期票据。
- 不向 Codex 自动发送，也不更改其审批或沙箱配置。Codex 可继续要求用户批准文件写入；这由 Codex 当前配置决定。
- 桥接 App 未安装、辅助控制权限未授予、Codex 未安装或票据过期时，网页显示可复制的安装提示或错误，不静默声称已完成。

## 验收

- 未授权用户不能创建或消费交接票据；票据绑定节点、创建者、短时过期且只能成功消费一次。
- 浏览器只发起自定义协议，不包含 Skill 正文；桥接端使用票据取回数据。
- 默认与导入 Skill 都会生成正确的目标路径和保真正文；提示明确要求不执行内容、不覆盖既有文件且不自动发送。
- 桥接端对非 HTTPS 来源、超长内容、重复/过期票据返回明确错误。
- 使用 macOS 真机确认协议注册、Codex 启动、辅助粘贴目标和 Enter 前状态。自动化替身测试不能代替真实 App 验收。

## 边界

本功能仅面向每位使用者自己的 Mac。平台服务器不替远端浏览器控制客户端桌面，也不将 Skill 直接写入服务器或用户目录。首次安装桥接工具及 macOS 辅助控制授权为一次性准备；未验证真实 Codex App UI 前不宣称端到端安装已验收。
