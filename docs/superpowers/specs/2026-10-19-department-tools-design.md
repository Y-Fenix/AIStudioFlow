# 部门常用工具入口与 API 适配器插槽

## 已确认范围

每个部门首页提供部门专属的常用工具网站入口。设计部门首期提供 Figma 与 Figma AI 的外链；各部门负责人可在本部门 `manifest.json` 维护工具名称和 HTTPS 地址。外链只负责打开服务网站，不表示平台已登录、已授权或已接通服务 API。

需要 API 能力的工具使用单独的适配器插槽。清单声明适配器标识、显示名、连接状态和凭据归属。凭据归属固定为平台管理员；凭据不写入部门 manifest、浏览器或部门 Skill。未实际注册且验证的适配器必须显示未配置。首期不实现 Figma API 调用、OAuth 或密钥保存界面。

## 边界

- 公共目录验证工具标识唯一且 URL 为无凭据 HTTPS。
- 浏览器外链使用新标签页并设置 `noopener noreferrer`。
- 部门负责人只修改本部门 manifest 与 UI，不修改公共权限、数据库或其他部门。
- 外链配置不是授权；适配器未来的 API 调用需由公共执行器经项目/部门权限门禁，并从服务器端管理员凭据存储取密钥。
- Figma API、Figma AI 功能可用性、企业授权、付费范围和真实数据读写都不在首期承诺内。

## 验收

验证五部门首页工具卡、设计 Figma/Figma AI 外链、链接协议校验和适配器凭据归属校验；确认页面不把未连接插槽显示为已连接，且外链没有 opener 权限。测试不得登录、写入或修改 Figma 内容。
