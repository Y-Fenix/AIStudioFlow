# 本地账号登录替代飞书登录

用户已要求直接改成本地注册登录，保留已确认的负责人审批和资源权限设计。

- 默认采用 `password` 模式，无需飞书应用、企业安装或 OAuth 回调。旧 OAuth 实现仅保留兼容，不在新界面提供入口，password 模式拒绝 OAuth 登录。
- 首次由服务器本机回环地址设置负责人账号、姓名和密码；禁止经反向代理或远程认领。绑定已有 `local` 用户，保留原工作室、项目、授权、日志及偏好；初始化事务只允许成功一次。无默认密码。
- 普通成员自行注册，默认 pending/member，不允许请求参数指定权限。审批分配复用现有工作室—项目—部门—节点—Skill 权限。
- 密码采用独立随机盐的 scrypt 哈希；只存哈希，不返回密码字段。账号忽略大小写，3–32 个英文字母、数字、点、下划线、连字符；密码 10–128 字符，支持 Unicode。登录错误统一提示。
- 会话 12 小时，Cookie HttpOnly/SameSite，HTTPS 配置启用 Secure；退出、禁用、修改或重置密码撤销会话。登录/注册/初始化有数据库持久化限流，不信任来访者伪造的代理 IP。
- 成员可修改自己的密码；平台负责人可重置其他本地账号密码。负责人忘记密码可通过服务器终端的交互工具恢复，不通过公开接口找回管理员身份。
- 本机预览允许回环 HTTP；团队部署仍需 HTTPS 保护密码传输，省去的是飞书配置。部署文档、生成器与预检改用本地账号配置。
- 明确的 `local_development=True` 仅供既有隔离测试/本机开发，限制回环、拒绝代理请求，默认服务不启用免登录模式。

验证：独立 SQLite 的 HTTP 与浏览器注册—等待—审批—登录—退出流程；初始化抢占、账号重复、错误密码、限流、跨站写入、越权、禁用和改密会话失效；已有权限/节点/Skill 测试回归。不触碰飞书、Git、Figma 或真实用户密码。
