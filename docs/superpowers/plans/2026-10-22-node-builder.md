# 节点积木与自定义流实施计划

用户授权：按推荐方案设计实现；共享范围为工作室 + 部门；常规选择自主完成。不做 Git/Figma 操作。

目标：可拖拽构造可用节点内容、共享团队模板，并把跨部门节点组成持久化可运行的自定义流。

- [x] 失败测试：积木验证、模板隔离与版本、蓝图应用、跨部门顺序执行、人工暂停/继续、失败/重启、撤权和旧结果拒收。
- [x] 公共积木 schema、模板服务、蓝图服务与运行状态机，独立目录维护。
- [x] 持久化运行队列，接公共模型能力和注册部门执行器；人工节点/测试证据门禁保留人工操作。
- [x] 三栏拖拽搭建器、预览、模板导入导出及实际运行面板，键盘替代操作。
- [x] 自定义流替代增长的默认入口，原 growth ID/历史数据兼容；跨部门节点库和流程运行。
- [x] 文档、独立扩展样例、权限后台、隔离数据库浏览器验收及回归检查。

补充设计：自定义流是项目资源，不冒充新部门。保存有序步骤和修订，可重复引用稳定部门节点 ID；运行展开当前蓝图/Skill/输入契约的快照。未注册执行器的节点使用人工交付步骤，不能伪装 Agent 运行；测试旧节点通过关联当前项目真实测试批次完成证据确认。画布支持积木和节点的添加/拖放/排序。当前版本不提供条件分支/循环/并行，也不执行网页上传的代码。
