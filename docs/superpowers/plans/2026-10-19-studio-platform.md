# StudioFlow A 正式化

目标：沿用已确认的 A 布局，工作室位于项目外层；右上角设置个人身份，刷新后按身份进入默认部门。现有测试任务保持可访问。

架构：沿用 Python HTTP + SQLite，新增工作室、个人偏好、项目节点工作区。22 个节点由服务端目录定义；测试六节点复用现有执行与证据门禁。其他部门先支持真实保存资料、Skill、交付物和人工审批，界面明确区分人工交付与 Agent 执行，不显示预置成功。

本轮执行在当前会话完成；不创建新会话、不提交或拉取 Git、不修改 Figma。

- [x] 数据层：旧库备份并幂等迁移；项目名称仅在所属工作室唯一；原任务与引用不变。
- [x] 工作室接口：新增、搜索、分页、进入；项目接口必须校验工作室归属。
- [x] 身份设置：负责人、产品、设计、开发、测试、发行增长；身份自动决定默认首页，其他部门仍可进入。
- [x] 工作区：各项目各节点独立保存输入、Skill、交付物、决策与操作日志；默认 Skill 可导入、导出、恢复。
- [x] A 版正式入口：去掉演示数据与比较器；真实工作室、项目与统计；复用现有测试工作台和 AI 配置。
- [x] 验证：迁移旧任务、工作室隔离、同名项目、非法身份/归属、并发旧版本拒绝；真实浏览器创建/切换/刷新/ESC/遮罩与窄屏；完整现有测试。

自动执行范围：本轮不把其他部门的人工交付冒充模型执行；真实 AI 自动研究、生图、代码修改和对外发布分别按后续工具接入支持，不由身份设置自动授权。
