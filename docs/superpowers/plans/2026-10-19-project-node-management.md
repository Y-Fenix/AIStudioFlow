# 项目节点管理实施计划

> 使用 executing-plans 在当前会话逐项执行，不派发子代理；用户已确认推荐设计。禁止 Git 拉取、提交、推送及 Figma 修改。

**目标：** 五部门按项目管理节点，稳定 ID、归档保留、独立授权和测试证据门禁兼容。

**架构：** `server/core/project_nodes.py` 统一提供项目节点注册、默认 Skill、配置版本及管理；现有目录只作为模板。界面保留位置索引用于渲染，通过 `node_keys` 取得稳定资源键。测试旧六阶段业务按原稳定键运行，不因展示排序变化重编号。
