# 个人工作区与项目公区验收

日期：2026-10-22。设计已获用户确认；实现为独立个人运行端、公区服务端及显式发布连接器。

## 已验证范围

全部发布测试使用临时数据目录，不上传真实需求，不调用真实模型，不发送真实飞书 Webhook。

- 协议和 HTTP：真实本地密码注册、待审批、审批后授权；服务端确定作者；项目/版本与节点校验；成员身份不自动授予发布权；中途撤权拒绝提交；修订冲突；重复操作与提交结果丢失后核对；撤下阻止历史与附件读取；哈希、路径穿越、大小与附件格式校验；过期暂存清理。
- 运行隔离：个人模式拒绝非回环监听，不启动提醒发送器，禁止运行结果排入群通知；公区模式不创建节点执行 worker、不加载部门执行器，拒绝个人工作区、模型、源码与任务接口，即使操作者为负责人。
- 默认数据库：三种运行模式使用不同默认路径；个人模式省略数据库参数时不会打开旧团队库。旧服务没有运行模式接口时，页面仅对 404 回退团队模式，不吞掉认证、权限、网络或服务异常。
- 受控导出：普通交付、测试选定产物、独立 Skill、工作流配置；需求和 Skill 分别选择；保留工作流任务指令、冻结继承或覆盖的有效 Skill；逐个引用节点检查导出权限；测试结果不带原始代码引用、模型轨迹或发布请求；过期会话保留本机预览且不发布。
- 提醒：只有公区成功提交才记录 `public_published` 事件，相同操作重试不会重复排队。发送端未连接真实飞书。
- Chrome：三套独立临时安装（个人 A、个人 B、公区），两个真实公区密码账号；5 条项目分页，明确确认上传，B 查看及复制，复制不改 B 原节点，A 后续修改不改公区快照，发布新修订、历史与深链接，撤下后副本保留，ESC/遮罩关闭，公区权限后台及提醒页面不请求个人 API；三套主题及 390px 移动宽度，版本按钮可见且顶部不重叠；无页面 JavaScript 异常。

复跑命令：

```sh
python3 -m unittest tests.test_public_area tests.test_public_area_http tests.test_public_area_client -v
python3 -m unittest discover -s tests
node --test tests/*.test.js
node tests/browser/public-area.cjs
```

浏览器脚本需要 Playwright 与 Chrome，可用 `STUDIOFLOW_PLAYWRIGHT_MODULE` 和 `STUDIOFLOW_CHROME` 指向本机实际路径。脚本自建服务和账号，不连接运行中的工作室数据库。

本次实际结果：Python 全量 537 项通过（73.876 秒），Node 全量 79 项通过；三实例 Chrome 公区流程脚本通过，包含旧服务缺少运行模式接口时的加载兼容验证。测试部门静态边界检查通过（4 个部门代码文件）；该检查不代表沙箱隔离或全部兼容入口已作架构审计。

## 交付边界

尚未验收两台真实 Mac 之间的公司网络、中央 HTTPS/证书/launchd、真实公区项目配置及真实飞书提醒。三套隔离服务的测试不代表真实跨机上线；未重新验证模型业务质量或既有测试节点执行效果。

现有 8766 服务保留团队兼容模式，其真实代码检测任务仍在更新，所以未重启。独立个人实例已在 `http://127.0.0.1:8767/` 启动，使用 `data/personal/platform.sqlite`；Chrome 实测旧服务登录页、新服务首次账号设置页均可显示，无页面 JavaScript 异常。旧任务的 933 条用例及原始产物 SHA256 与实施前记录一致。要获得每人个人数据隔离，需按[部署说明](personal-public-area.md)分别安装个人端，并另建公区服务；不能把现有多人共享数据库解释成个人工作区。

公区复制为不执行的独立内容副本，当前只支持查看与手动复用文字，不自动导入工作流或运行 Skill。公区需具有发布归属的对应节点，自定义节点结构不自动同步。附件并非通用秘密扫描/消毒；二进制内容和元数据需用户自行检查。
