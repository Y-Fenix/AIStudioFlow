## 使用和已知范围

本地服务 `http://127.0.0.1:8766/`：页面及新增JS/CSS返回200，正式服务保持账号认证，未登录的受保护API返回401。沿用既有局域网监听与认证配置；没有用开发绕过模式运行。跨设备网络和 Mac 开机自启仍需实际部署环境验证。

普通节点进入“搭建节点” → 添加/配置 → 保存并应用 → 运行；有已保存蓝图时重新进节点直接展示运行工作区。左侧“自定义工作流” → 工作流列表 → 节点首页 → 节点工作区；需要配置时点击“编辑流程”。新版导航验证见 [自定义工作流导航验收](custom-workflow-navigation-acceptance.md)。人工步骤填写或审核后继续。模板选择所属部门，发布新版本或添加到当前组合；已有实例不会随模板升级漂移。

当前为单Mac顺序队列，无条件分支、循环或并行。工具外链只打开页面；未接入真实执行器的部门节点明确等待人工交付，不冒充工具执行。固定测试节点仍在专用工作台完成真实静态流程后关联批次，不能自动伪造测试证据。原普通节点自动继续仍使用原adapter队列，积木组合通过自定义流运行。公开积木扩展是受信任仓库代码，不接受网页上传脚本，不提供运行时沙箱。
