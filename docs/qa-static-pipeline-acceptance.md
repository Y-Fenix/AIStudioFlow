## 修复与失败复现

1. 提单页触发回归时，后台原来按任务阶段 4 读取提单 Skill。现在复用权限检查返回的操作节点 5 选择回归 Skill；任务阶段和并发修订检查不变。
2. 归因原来用字符串首次出现位置推断行号，重复代码会标错。现在优先验证准确行号，仅唯一引用可纠正；歧义拒绝猜测。同一失败重复分组也拒绝。
3. 混合报告原来有未验证项就显示 incomplete，掩盖已发现缺陷。现在优先显示 failed，同时保留未验证项计数及逐项状态。
4. 真实模型读取短文件时，请求 1–200 行会被旧读取器拒绝，造成多轮补问。现在合法的有限窗口截到 EOF；越界起点、超过 200 行和 20KB、目录及引用校验仍受限制。

以上问题均先通过失败测试复现，再修改实现。权限函数仅增加操作节点返回值，未扩展权限或修改持久化字段含义，接口缺口记录于测试部门 README。
