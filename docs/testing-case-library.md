# 版本测试工作台与用例库

2026-11-10，按用户确认的 A 方案落地。

## 使用

测试节点顶部切换「当前工作台 / 用例库」。在当前工作台按版本及批次选择工作对象；「新建测试批次」可选择已有版本或新建版本，并填写批次名称。新批次从用例节点开始，不要求旧批次完成或清空。

旧批次没有真实业务版本记录，统一显示「未分配版本」。在用例库点击对应批次的「归属版本」，手动归属到 1.0.0 等实际版本。调整归属不会修改用例或旧快照里的原版本信息。在途任务不能调整版本归属。

用例库按批次显示最近保存的一套用例；生成或编辑成功立即自动保存为草稿，确认后保存已确认快照。用例状态与测试进度分开展示，已确认用例不代表执行通过。支持名称搜索、版本/状态筛选、10/20/50/100 分页、打开批次及查看只读历史快照。快照详情内每页显示 20 条用例，需求及 Skill 正文按需展开。

复制会新建独立批次，复制需求快照、用例及捕获的原 Skill；需求 ID 和引用重新映射，审核需重做。不复制执行基线绑定、执行结果、归因、Bug 目标、远端状态、回归结论或全自动委托。原 Skill 明确导入为新批次的独立版本，保留真实操作者。若旧快照未保存原 Skill 正文，必须勾选同意使用当前默认 Skill，不能假装还原原规则。

旧批次进入后续节点或结束后，需求来源页明确说明为什么不能重新生成，并提供新建批次入口；不再允许点击一个已知会被后端拒绝的生成按钮。需要修订同一批次时原有显式重置仍保留，历史快照不删除。

刷新后 URL 保留当前任务和节点。当前工作台与用例库之间切换保留同一任务/节点修订的未保存输入；刷新前未保存输入仍需保存。在独立部门流程中，新建批次会进入默认工作台，原流程与批次绑定不改写。

## 权限与存储

公共实现：`server/core/testing_library.py`；只新增 `testing_versions`、`testing_batch_versions`、`testing_case_snapshots`、`testing_library_meta`。原 tasks.revision 仍为数据修订，稳定节点 ID、已有持久化字段含义与接口均不改义。生命周期由 Store 在原事务内接线，部门前端只调用授权接口。

查看要求 testing:0 view。版本创建、批次创建及归属复用 testing:0 edit + testing content create。复制另要求用例 import/export 及 Skill view/import/export。快照 Skill 正文与代码基线分别按 Skill view / testing:1 view 过滤；项目和工作室隔离，未登录不能访问。用例库不自动发布到项目公区。运行模式和既有工作室/项目可见范围保持不变，不将团队数据库冒充成单人私有数据库。

历史迁移仅捕获启动时仍存在的用例，不推断版本号，不还原已丢失的生成历史或 Skill 正文。生成失败或结果过期不登记成功快照；只读浏览不更新业务状态。旧数据库已在本机升级前备份，私有备份不进入代码。

## 版本管理与重命名补充

当前工作台的版本选择旁、用例库顶部均提供「版本管理」。选中具体版本后点「重命名版本」；列表中可以单独「重命名批次」。管理列表包含未生成用例的空批次，支持搜索、版本筛选及每页 10 个批次。

重命名复用用例编辑和测试内容创建权限。版本名在同一项目内不允许重复；版本、批次保存时核对打开时的原名称，拒绝覆盖他人更新。只修改名称并写操作日志，不改变任务修订、在途任务基线、进度及用例数据；关联批次读取新版本名称，历史快照保留原版本名称。没有修改任何真实业务版本或批次名称。

补充验证：用例库单测 15 项；含原生成、重置、队列和授权的 Python 组共 36 项通过，89 项 JS 测试通过。用例库浏览器回归新增版本/空批次分别重命名、重名冲突、刷新持久化和 ESC，独立/嵌入入口均通过；FOCUS 回归仍完整显示 5 条用例。实际服务备份后加载新代码，任务、版本、归属与快照逐行对比重启前一致。截图 `data/visual-review/qa-version-manager-embedded.png` 为隔离样例。

## 旧批次设置项目版本与删除（2026-11-10）

在「版本管理」选择「未分配版本」，点击「设置项目版本」，可创建版本或归入已有版本。界面明确显示本项目待归属批次数；应用到所有未分配且未删除批次，不要求先填写批次名称，不改写批次标题。若只想调整某一批次，仍使用用例库的「归属版本」。

具体版本提供「删除版本」，批次提供「删除批次」。均先读取影响范围，再弹二次确认框，支持取消、关闭、ESC 和点击遮罩退出。删除版本只移除版本，将关联批次归回「未分配版本」，不级联删除批次；删除批次从工作台选择、项目摘要及用例库隐藏。历史证据保留在本机，不删除飞书记录。新增 `testing_library_deleted` 记录删除者与时间；原表与快照保留，当前界面不提供回收站恢复入口。删除后的版本名可重新创建。

删除需要 testing:0 view/delete 和测试 content.delete，与创建权限独立。服务端在事务内核对确认标志、影响范围摘要及在途状态；确认期间名称、任务修订或版本成员变化均拒绝删除，须重新确认。排队/运行中任务、节点助手、正在发送的飞书请求禁止删除；绑定活动独立流程的批次须先归档流程。批次删除同时关闭其全自动委托，后续任务读取拒绝访问该批次。删除当前批次后切换剩余批次，删除最后一个后清空工作区及内外层 URL 的批次引用。
