# StudioFlow 工作台设计样板 · 2026-11-10

仅用于确认视觉与交互方向。不连接真实 API，不修改工作台、任务或数据库。933 条、69 分批、12 问题、来源和运行信息均为演示数据。表格仅含 8 个示例，翻页重复用于交互演示。

- A / FOCUS：浅色、用例优先，横向紧凑流程；日志、助手和详情按需侧滑打开。推荐作为默认方向。
- B / CONTROL：石墨深色、窄导航、纵向节点、右侧运行观察；适合长任务监控。
- C / REVIEW：暖白与森林绿，需求和用例并排；适合覆盖评审。

三套统一：项目/版本/流程分层切换；内容区独立滚动；底部保存与确认固定；低频操作收起；侧滑详情响应 ESC、遮罩点击、焦点圈定与关闭后焦点恢复。抽屉内非业务入口仅演示位置，均明确标注。只读展示不等于真实功能实现。

预览：在本目录运行 `python3 -m http.server 8791 --bind 127.0.0.1`，打开 `http://127.0.0.1:8791/?v=A`（B、C 同理）。

实际验证：Chrome + Playwright，三套 1500×1000 和 390×844；抽屉、ESC、遮罩、选择、翻页通过，窄屏无横向溢出，无 JS pageerror。截图是 HTML 实际渲染。未验证真实节点执行或数据持久化。
